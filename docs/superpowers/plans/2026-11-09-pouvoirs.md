# Pouvoirs — plan de réalisation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** suivre les pouvoirs sur la fiche (objet « Pouvoir », glisser-déposer), remplir un compendium local des disciplines (V20 et V5) depuis la vault, et rendre sphères et Arété cliquables pour un jet.

**Architecture:** nouveau type d'objet `pouvoir` (TypeDataModel + fiche d'objet) ; liste groupée dans l'onglet Avantages ; parseur Python des notes de disciplines (testé avec `unittest`) qui produit un JSON importé par le script JS existant `tools/importer-compendium.js` (généralisé) ; sphères et Arété déclarées « jetables » dans `etat.hbs`.

**Tech Stack:** Foundry VTT 14.369, Node 24 (`node --test`), Python 3 (`PYTHONUTF8=1 python -m unittest`).

**Spec:** `docs/superpowers/specs/2026-11-09-pouvoirs-design.md`

## Global Constraints

- Aucun bouton « Utiliser », aucun message de chat, aucune dépense automatique liée aux pouvoirs.
- Éditions des pouvoirs : `V20` (éditions classiques), `V5`, `autre` ; les deux cohabitent.
- Catégories : `discipline`, `don`, `rite`, `autre`.
- Compendium du monde `world.pouvoirs` (local, non publié) ; aucune donnée de la vault dans le dépôt.
- Textes en français dans `lang/fr.json` ; `check_system.py` : 0 erreur, 0 avertissement ; identité git noreply.

## Review Focus

1. Pouvoir glissé deux fois sur la même fiche → deux objets (comportement Foundry par défaut, accepté) ; il ne doit pas apparaître dans l'équipement ni dans l'onglet Combat.
2. Note de discipline sans « Niveau N » ni tableau V5 → ignorée et signalée, sans planter l'import.
3. Pouvoir au nom ou à l'effet contenant `<`, `&`, liens Obsidian `[[a|b]]` → texte propre, HTML échappé.
4. Fiche d'un non-mage → aucune sphère ni Arété jetable ; mage avec sphère à 0 → jet possible (règle « capacité à 0 », +2 diff.).
5. Réimport du compendium → vidé puis rempli, sans doublons.
